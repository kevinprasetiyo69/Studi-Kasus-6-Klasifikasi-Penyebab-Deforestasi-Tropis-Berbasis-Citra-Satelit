# Studi-Kasus-6-Klasifikasi-Penyebab-Deforestasi-Tropis-Berbasis-Citra-Satelit
Penerapan Machine Learning untuk mendeteksi penyebab langsung deforestasi tropis. Model mengintegrasikan data reflektansi optik dan radar, mengatasi data tidak seimbang, serta dievaluasi menggunakan Macro F1-Score guna memastikan deteksi akurat pada kelas minoritas.
